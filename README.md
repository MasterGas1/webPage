
## Getting Started

### Node version :20.14.0

First run the dependencies installation:
```
npm install
# or
npm i
# or
yarn add
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
